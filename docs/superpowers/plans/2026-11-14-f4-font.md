# F4: a more premium font (plan)

- **Date:** 2026-11-14
- **Spec:** `todo.md` F4 and section 6.1 of `docs/superpowers/specs/2026-11-14-ecosystem-design.md`
- **Track:** F4 of the ecosystem build; one worker, no order constraints with the other tracks.

## Decisions (Leo, 2026-11-14)

Leo compared renders of Nunito, Inter, Geist, Figtree and Manrope on both boards.

1. **Dock and wearable: Manrope** (SIL OFL 1.1, Google Fonts). Manrope stops at weight 800, so:

   | Atlas the UI asks for | Drawn at |
   |---|---|
   | 900 (all sizes) | Manrope 800 |
   | 800 (all sizes) | Manrope 700 |

   The atlas names and sizes stay, so no UI code changes.
2. **iPhone app: SF Pro**, the system font. `Theme.rounded` drops `design: .rounded`; nothing is bundled. The
   function keeps its name so other tracks' call sites keep compiling.
3. **The pixel digits** (clock, minutes, "Due") stay.

## Files

- `firmware/lib/gfx/tools/font_build.html`: loads Manrope 700/800 from Google Fonts and maps the weights.
- `firmware/lib/gfx/src/fonts.cpp`: regenerated by `python3 firmware/lib/gfx/tools/font_build.py`; `fonts.h`
  comment.
- `ios/CTATracker/Design/Theme.swift`, plus the three direct `design: .rounded` calls in `Design/RouteCard.swift`
  and `Map/MapScreen.swift` (fixed sizes, so they stay `.system(size:weight:)` rather than going through the
  Theme). The other 36 call sites already use `Theme.rounded`.
- Docs: `docs/handheld-ui.md`, `docs/superpowers/specs/2026-11-05-ios-redesign-design.md`, `todo.md`.

- `firmware/lib/gfx/tools/OFL.txt`: Manrope's license (from google/fonts `ofl/manrope/OFL.txt`); the generated
  `fonts.cpp` names it.
- Stale "Nunito" fixed in `gfx2d.h`, `library.json` and `firmware/handheld/mock/README.md`.

No TTF goes into git. `font_build.html` pins one Google Fonts woff2 (`manrope/v23`), and its output is
byte-identical to a build from the google/fonts `Manrope[wght].ttf`. If the font fails to load, the page writes
nothing and `font_build.py` exits with an error instead of building a fallback-font atlas.

about 600 B.
