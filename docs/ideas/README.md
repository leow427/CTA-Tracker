# Ideas (temporary)

Exploratory work that isn't part of the spec yet. Nothing here is a contract: the spec in `docs/superpowers/specs/` wins wherever the two disagree. Files get promoted into the spec or deleted once a decision is made.

| File | What it is |
|---|---|
| `2026-11-04-handheld-ui-mockup.html` | Interactive mockup of the handheld's round 466×466 AMOLED UI in the iPhone app's pixel style, updated 2026-11-07 to Leo's decisions: black on every screen, Trackie straight on black (no tile), one card per line and direction at a station and per route and direction at a bus stop, each saying where it ends and the way it goes. Home, Trains/Buses lists, stop detail, the stretch-goal map, dim always-on, docked, pairing and first-run states, plus a panel-power meter. Open it in a browser. The written guide is `docs/handheld-ui.md`. |
| `2026-11-05-ios-diorama-mockup.html` | Scratch mockup of the iPhone app's diorama map (see the iOS redesign spec). |
| `2026-11-11-dock-ui-mockup.html` | Mockup of the dock's 4.3" portrait screen (480×800, spec §7) in the handheld's look, drawn only with `gfx2d`-style calls so it ports to C++ like the handheld's `ui.cpp`. Status strip with Trackie and a map button, three stop cards with 3 arrival tiles each, a map mode framed on the three approach zones with up to 3 live vehicles per line, the stop picker, pairing, setup, offline and night states, the LED rows on the faceplate to the right (as in the CAD), and a list of the font sizes it uses. `2026-11-11-dock-ui-mockup.png` and `2026-11-11-dock-ui-map.png` are the two main screens; open the HTML with `#state=N&solo` (screen only) or `#state=N&device` (with the LEDs) to export any state. Under critique. |
| `2026-11-12-pixel-map.js`, `2026-11-12-chicago-basemap.js` | The pixel map of Chicago under both mockups' map pages (design: `docs/superpowers/specs/2026-11-12-pixel-map-design.md`). `chicago-basemap.js` is generated by `tools/basemap_build.py` from OpenStreetMap (BBBike's Chicago extract of 2026-11-08, fetched by `tools/basemap_fetch.py`) and CTA's GTFS: the lake, rivers, parks, beaches and three classes of streets for the whole CTA area, packed in 579 KB, plus every L line and the 22 at 2 m. `pixel-map.js` turns it into cells and paints them in one of five styles (Night, Navy, 8-bit, Blueprint, Quiet), switchable in each mockup's "Map style" control. **Map data © OpenStreetMap contributors, ODbL 1.0** (openstreetmap.org/copyright). The dock firmware carries it in the Quiet style Leo picked (2026-11-13; `firmware/lib/cta/src/basemap.*`). Serve the folder over HTTP (`python3 -m http.server -d docs/ideas`) or open the HTML directly; the two scripts load beside it. |
| `2026-11-12-pixel-map-styles.png` | The five map styles side by side: the dock framed on the picks, zoomed out, and the handheld map. Leo picks one. |
